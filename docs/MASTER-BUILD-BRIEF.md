# Master build brief — Connecticut Party Rentals site

**Purpose:** Single source of truth for landing pages, info pages, and future Goodshuffle/wishlist integration. Improve existing pages; do not replace wholesale unless necessary.

---

## Main goal

Make every landing page and info page a **high-trust, human-first decision page** that helps customers:

1. Understand the rental  
2. Understand the planning process  
3. Decide if it fits their event  
4. Move toward **a quote** or **building a wishlist**

Each page should:

- Target **one main search intent**  
- Feel **unique**  
- Avoid filler, AI-sounding copy, or repeated structures with only a few words changed  

**Improve** existing pages instead of overwriting them. Keep the current style unless readability, spacing, or trust clearly need refinement. Leave room for **Goodshuffle** `item` / `image` IDs so products can later connect to wishlist or waitlist flows.

---

## Core rules (every page)

1. Every section must do **one of three things:** build **trust**, help the customer **decide**, or move them toward **action**.  
2. Write for **customers first**, search engines second.  
3. Copy: **clean, specific, natural** — no generic sales padding.  
4. **Design system:** keep it; **tighten** spacing, **improve** hierarchy, **scan** easier.  
5. Where product cards or featured rentals appear: leave clean hooks for:
   - `goodshuffleItemId`  
   - `goodshuffleImageId`  
   - Future **wishlist / waitlist** action  

---

## Phases (execution order)

### Phase 1: Tent rentals page

**Goal:** Main money page — clearest starting point for anyone searching for tents.

**Improve:** Hero, trust strip, quick-answer block, tent type explanations, sizing help, common use cases, surfaces/setup notes, weather planning, strong quote CTA. Add **compact featured rental cards** with placeholders for Goodshuffle integration.

### Phase 2: Wedding tent rentals page

**Goal:** More premium and planning-focused.

**Improve:** Hero, trust signals, planning boxes, popular wedding setups, weather/rain backup, lighting, comfort, wedding-specific FAQs. Elegant and helpful, not bulky. Room for **featured wedding rental items** and linked Goodshuffle IDs for later wishlist behavior.

### Phase 3: Table and chair rentals page

**Goal:** Expand from thin page to a real decision page.

**Include:** Table types, chair types, event use cases, pairing recommendations, quantity guidance, delivery/setup notes, add-on logic. Make backyard party, wedding, graduation, and corporate fit obvious. **Featured item cards** with placeholders for product image and item IDs.

### Phase 4: Backyard, graduation, private party landings

**Goal:** Event-intent pages, not tent-page clones.

**Each:** Guest flow, food tables, shade, seating, weather backup, yard/driveway concerns, common package combinations. **Consistent layout**, **unique** advice and examples. Product/wishlist hooks where relevant.

### Phase 5: Corporate, school, community, festival pages

**Goal:** Operationally smart.

**Focus:** Guest flow, check-in, branding areas, vendor space, public circulation, timing, weather readiness, larger setup logistics. Concise and decision-oriented. Common setup types + **featured rentals** + Goodshuffle hooks.

### Phase 6: Service area pages

**Do not** ship thin city-swap templates.

**Improve priority towns first** — genuinely local: setup considerations, common event types, access/logistics, local trust cues, relevant internal links. Same style; copy **unique** per area.

### Phase 7: Info pages and guides

**Goal:** Trust, SEO, AI readability — **not** blog filler.

**Topics (examples):** Tent sizing, driveway/patio setups, rain backup, sidewalls, lighting, planning checklists, table/chair counts, what to know before booking. Educate clearly; **link** into landing pages; build confidence to contact.

---

## Section formulas

### Landing pages

**Hero → trust strip → quick answer → who it’s for → popular setups or featured rentals → planning / helpful guidance → FAQs → final CTA**

Keep each block **compact** and **purposeful**. Featured rental sections: reserve structure for Goodshuffle item/image refs and later wishlist.

### Info pages

**Question-based headline → direct answer at top → simple explanation → practical planning points → related rentals or recommended next steps → FAQ if needed → internal links** to the right landing pages.

Helpful and human; not machine filler.

---

## Build standard

- Do **not** rewrite from scratch unless necessary — **upgrade** what exists.  
- Keep the **current visual direction** unless trust, readability, or spacing clearly need change.  
- Outcome: every page **more useful, more specific, more unique**, and **ready** for Goodshuffle-connected rental selection later.
